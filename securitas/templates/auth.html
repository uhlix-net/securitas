LDAP / Active Directory

Users sign in with their directory user name and password. Securitas binds with the service account below to find the user and their groups, then checks the password by binding as the user. Use ldaps:// (or StartTLS); the server's CA must be in the deployment's CA bundle. Changes apply to the next sign-in.
