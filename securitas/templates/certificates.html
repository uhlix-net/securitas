Certificates

The TLS certificate the web site is served with (the ingress Secret). Replace it with a new certificate and private key: PEM files (certificate, key and, if your CA has one, the intermediate chain) or a PFX / PKCS#12 file with its password, as a Windows CA exports it. Securitas checks that the key belongs to the certificate, that it is valid now and that it covers {% if hosts %}{{ hosts|join(", ") }}{% else %}the site's names{% endif %}, then writes it to the Secret; the ingress picks it up by itself. Securitas does not keep a copy of the key. Every replacement is in the audit log.
