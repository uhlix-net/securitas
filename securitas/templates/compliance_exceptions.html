A baseline exception applies to every host checked against that benchmark (by name, so it carries over to a newer version of the same role); a server exception applies to one host and wins over a baseline exception for that host. Compliance scans after an exception is saved report the rule as Accepted with its reason; accepted rules count towards the score. Exceptions are added and changed on a host's result page (open a failed rule from Report); every change is in the audit log.
