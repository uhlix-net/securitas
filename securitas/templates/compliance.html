Compliance benchmarks

The benchmarks hosts will be checked against. Each one is a Securitas benchmark package: the rules exactly as the official CIS benchmark document states them (ID, title, Automated or Manual, profiles) together with the checks that test them, stored under its name and CIS version (for example RHEL9-CIS-2.0.0) with the date it was uploaded. Packages are built from the official CIS PDF with tools/cis_package.py. Ansible-Lockdown role zips can still be loaded, but they carry no CIS Automated/Manual labels. Several versions can be loaded side by side; one per operating system is active and is the one used for checks. The first benchmark loaded for an operating system becomes its active one. Removing a benchmark removes its rules and the stored zip.{% if not editable %} Only admins can upload, change or remove benchmarks.{% endif %}
