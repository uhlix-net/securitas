Compliance benchmarks

The benchmarks hosts will be checked against. Each one is an Ansible-Lockdown role, stored under its name and version (for example RHEL9-CIS-2.4.2) with the date it was uploaded. Several versions can be loaded side by side; one per operating system is active and is the one used for checks. The first benchmark loaded for an operating system becomes its active one. Removing a benchmark removes its rules and the stored zip.{% if not editable %} Only admins can upload, change or remove benchmarks.{% endif %}
